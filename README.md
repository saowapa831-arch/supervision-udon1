## ✨ ความสามารถของระบบ

- **ระบบสมาชิก** — ลงชื่อเข้าใช้ / สมัครสมาชิก / เข้าชมแบบผู้เยี่ยมชม (อ่านอย่างเดียว)
- **26 ห้องนิเทศ** พร้อมแถบสีและไอคอนเฉพาะแต่ละห้อง
- **🏅 ห้องผลงาน / รางวัล** — คลังเกียรติบัตร 4 ประเภท (รางวัล / อบรมพัฒนา / วิทยากร / คณะทำงาน) คลิกที่ประเภทเพื่อกรองดูได้
- **อัปโหลดไฟล์ได้ทุกเมนู** — ลากวางหรือเลือกไฟล์ เลือกพร้อมกันได้หลายไฟล์ **ไฟล์ละไม่เกิน 200 MB** รองรับ
  - 🖼️ รูปภาพ — JPG, JPEG, PNG, GIF, WEBP, BMP, HEIC
  - 📕 PDF
  - 📘 Word — .doc, .docx  |  📗 Excel — .xls, .xlsx  |  📙 PowerPoint — .ppt, .pptx
  - 🎬 วิดีโอคลิป — MP4, MOV, AVI, MKV, WEBM, M4V, 3GP
  - 🎵 เสียง — MP3, WAV, M4A, AAC  |  🗜️ ไฟล์บีบอัด — ZIP, RAR, 7Z
- **แสดงสถานะการอัปโหลดทีละไฟล์** พร้อมแสดงพื้นที่จัดเก็บที่ใช้ไป
- **แสดงผลงานและดาวน์โหลดไฟล์** — ดูตัวอย่างรูปภาพ / วิดีโอ / PDF ได้ในหน้าเว็บ
- **Dashboard รายห้อง** — สรุปจำนวนไฟล์ แยกตามหัวข้อย่อย สัดส่วนประเภทไฟล์ ผู้อัปโหลดสูงสุด
- **Dashboard ภาพรวม** — สถิติผู้เข้าชมรายวัน 14 วัน สถิติสะสม จำนวนผลงานรายห้อง ครู/โรงเรียนที่ส่งผลงานสูงสุด
- **สถิติผู้เข้าชม** — รายวันและภาพรวมทั้งหมด แสดงทั้งบนแดชบอร์ดและส่วนท้ายเว็บ
- **ปฏิทินนัดหมาย PLC / นิเทศ / Coaching / อบรม** — เพิ่ม ดู และลบนัดหมายได้
- **ช่องขอคำแนะนำ / ขอความช่วยเหลือ / แสดงความคิดเห็น** — มีทุกห้อง พร้อมระบบตอบกลับ
- **Help Desk + FAQ** — รวมคำถามจากทุกห้องไว้ในที่เดียว
- **สิทธิ์ผู้ดูแลระบบ** — ลบไฟล์ใดก็ได้ จัดการสมาชิก รีเซ็ตรหัสผ่าน แก้ข้อความประชาสัมพันธ์ สำรอง/กู้คืนข้อมูล
- **Prompt Library + เครื่องมือ AI** สำหรับครู และข้อมูล CEFR สำหรับภาษาอังกฤษ
- **ใช้งานได้ทุกอุปกรณ์** — คอมพิวเตอร์ / โน้ตบุ๊ก / iPad / แท็บเล็ต Android / มือถือ iPhone และ Android

## 🚀 วิธีอัปขึ้น GitHub Pages (ใช้งานได้ทันที)

1. เข้า <https://github.com> แล้วลงชื่อเข้าใช้ (ถ้ายังไม่มีบัญชี ให้สมัครก่อน — ฟรี)
2. กด **+** มุมขวาบน → **New repository**
3. ตั้งชื่อ เช่น `supervision-udon1` → เลือก **Public** → กด **Create repository**
4. ในหน้า repository กด **uploading an existing file**
5. ลากไฟล์ **`index.html`** (และ `README.md` ถ้าต้องการ) มาวาง → กด **Commit changes**
6. ไปที่แท็บ **Settings** → เมนูซ้าย **Pages**
7. ที่ **Source** เลือก `Deploy from a branch` → Branch: **main** / โฟลเดอร์ **/ (root)** → กด **Save**
8. รอประมาณ 1–2 นาที เว็บจะพร้อมใช้งานที่

```
https://<ชื่อผู้ใช้ GitHub ของท่าน>.github.io/supervision-udon1/
```

## 📱 การใช้งานบนมือถือและแท็บเล็ต

เปิดลิงก์เว็บในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งแอป และสามารถ **เพิ่มไอคอนไว้หน้าจอหลัก**
เพื่อเปิดใช้งานได้เหมือนแอปจริง

**iPhone / iPad (Safari)**

1. เปิดเว็บใน **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) ด้านล่างจอ
3. เลื่อนหา **เพิ่มไปยังหน้าจอโฮม** (Add to Home Screen) → กด **เพิ่ม**

**Android (Chrome)**

1. เปิดเว็บใน **Chrome**
2. กดจุดสามจุด ⋮ มุมขวาบน
3. เลือก **เพิ่มลงในหน้าจอหลัก** (Add to Home screen) → กด **ติดตั้ง**

> ⚠️ ข้อมูลบนมือถือกับบนคอมพิวเตอร์เป็นคนละชุดกัน (เก็บแยกตามเครื่องและตามเบราว์เซอร์)
> หากต้องการย้ายข้อมูล ให้ใช้ ⚙️ ตั้งค่าระบบ → 📦 สำรองทั้งหมด แล้วนำไปกู้คืนในอีกเครื่อง

## 💾 ข้อควรทราบเรื่องการเก็บข้อมูล

ระบบนี้เป็นเว็บไฟล์เดียว ทำงานได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล
ข้อมูล (สมาชิก ไฟล์ ข้อความ ปฏิทิน สถิติ) จะถูกเก็บไว้ใน **เบราว์เซอร์ของแต่ละเครื่อง**
(localStorage และ IndexedDB)

**หมายความว่า:**

- ✅ เปิดใช้งานได้ทันที ไม่มีค่าใช้จ่าย ไม่ต้องตั้งค่าอะไรเพิ่ม
- ✅ ข้อมูลยังอยู่แม้ปิดเบราว์เซอร์หรือปิดเครื่อง
- ⚠️ ไฟล์ที่อัปโหลดจากเครื่องหนึ่ง **จะไม่ปรากฏบนเครื่องอื่น**
- ⚠️ หากล้างประวัติการใช้งานเบราว์เซอร์ ข้อมูลจะหายไป

**คำแนะนำ:** ผู้ดูแลระบบควรกด **⚙️ ตั้งค่าระบบ → 📦 สำรองทั้งหมด (รวมไฟล์แนบ)** เป็นประจำ
และสามารถกู้คืนได้ด้วยปุ่ม **📤 กู้คืนจากไฟล์สำรอง**

หากต้องการให้ครูทุกคนเห็นข้อมูลชุดเดียวกันแบบออนไลน์จริง สามารถต่อยอดเชื่อมฐานข้อมูล
Firebase หรือ Google Sheets เพิ่มเติมได้ในภายหลัง

## 🔎 ทำให้ค้นหาเจอใน Google

เว็บนี้ติดตั้ง SEO ไว้ครบแล้ว (title, meta description, keywords, Open Graph, Schema.org JSON-LD,
canonical, robots.txt, sitemap.xml และเนื้อหาภาษาไทยที่ Google อ่านได้บนหน้าแรก)
แต่ Google จะยังไม่รู้จักเว็บใหม่จนกว่าจะแจ้งให้ทราบ — ทำตามนี้ครั้งเดียว

**1. อัปโหลดไฟล์ให้ครบ**

ต้องมีไฟล์เหล่านี้ใน repository: `index.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`
และโฟลเดอร์ `assets/` (ใช้แสดงรูปตอนแชร์ลิงก์ในไลน์/เฟซบุ๊ก)

**2. แจ้ง Google ผ่าน Search Console**

1. เข้า <https://search.google.com/search-console> ลงชื่อเข้าใช้ด้วยบัญชี Google
2. กด **Add property** → เลือกกล่องขวา **URL prefix** → วาง
   `https://saowapa831-arch.github.io/supervision-udon1/` → **Continue**
3. ยืนยันตัวตนด้วยวิธี **HTML tag** → คัดลอกบรรทัด `<meta name="google-site-verification" ...>`
   ที่ได้มา แล้วนำไปวางในไฟล์ `index.html` ใต้บรรทัด `<meta charset="UTF-8">`
   จากนั้นอัปโหลดไฟล์ทับขึ้น GitHub อีกครั้ง แล้วกลับมากด **Verify**
4. เมนูซ้าย **Sitemaps** → ช่อง Add a new sitemap พิมพ์ `sitemap.xml` → **Submit**
5. เมนูซ้าย **URL Inspection** → วาง URL เว็บ → กด **Request Indexing**

**3. รอ Google เก็บข้อมูล**

โดยทั่วไปใช้เวลา **3–14 วัน** จึงจะค้นหาเจอ (เว็บใหม่ต้องใช้เวลาสร้างความน่าเชื่อถือ)
ตรวจสอบว่า Google เก็บข้อมูลแล้วหรือยัง โดยพิมพ์ในช่องค้นหา Google ว่า

```
site:saowapa831-arch.github.io/supervision-udon1
```

ถ้าขึ้นผลลัพธ์ = Google เก็บข้อมูลแล้ว

**4. เร่งให้ติดอันดับเร็วขึ้น**

- แชร์ลิงก์เว็บในกลุ่มไลน์ เฟซบุ๊ก และเว็บไซต์ของเขตพื้นที่ (ยิ่งมีเว็บอื่นลิงก์มา Google ยิ่งเชื่อถือ)
- ใส่ลิงก์ไว้ในลายเซ็นอีเมล และเอกสารเผยแพร่ต่าง ๆ
- เข้าใช้งานและอัปเดตเนื้อหาสม่ำเสมอ

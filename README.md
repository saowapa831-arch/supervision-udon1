## ✨ ความสามารถของระบบ

- **ระบบสมาชิก** — ลงชื่อเข้าใช้ / สมัครสมาชิก / เข้าชมแบบผู้เยี่ยมชม (อ่านอย่างเดียว)
- **25 ห้องนิเทศ** พร้อมแถบสีและไอคอนเฉพาะแต่ละห้อง
- **อัปโหลดไฟล์ได้ทุกเมนู** — ลากวางหรือเลือกไฟล์ รองรับ PDF, Word, Excel, PowerPoint, รูปภาพ, วิดีโอ, เสียง, ZIP (ไฟล์ละไม่เกิน 25 MB)
- **แสดงผลงานและดาวน์โหลดไฟล์** — ดูตัวอย่างรูปภาพ / วิดีโอ / PDF ได้ในหน้าเว็บ
- **Dashboard รายห้อง** — สรุปจำนวนไฟล์ แยกตามหัวข้อย่อย สัดส่วนประเภทไฟล์ ผู้อัปโหลดสูงสุด
- **Dashboard ภาพรวม** — สถิติผู้เข้าชมรายวัน 14 วัน สถิติสะสม จำนวนผลงานรายห้อง ครู/โรงเรียนที่ส่งผลงานสูงสุด
- **สถิติผู้เข้าชม** — รายวันและภาพรวมทั้งหมด แสดงทั้งบนแดชบอร์ดและส่วนท้ายเว็บ
- **ปฏิทินนัดหมาย PLC / นิเทศ / Coaching / อบรม** — เพิ่ม ดู และลบนัดหมายได้
- **ช่องขอคำแนะนำ / ขอความช่วยเหลือ / แสดงความคิดเห็น** — มีทุกห้อง พร้อมระบบตอบกลับ
- **Help Desk + FAQ** — รวมคำถามจากทุกห้องไว้ในที่เดียว
- **สิทธิ์ผู้ดูแลระบบ** — ลบไฟล์ใดก็ได้ จัดการสมาชิก รีเซ็ตรหัสผ่าน แก้ข้อความประชาสัมพันธ์ สำรอง/กู้คืนข้อมูล
- **Prompt Library + เครื่องมือ AI** สำหรับครู และข้อมูล CEFR สำหรับภาษาอังกฤษ
- ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ

## 🚀 วิธีอัปขึ้น GitHub Pages (ใช้งานได้ทันที)

1. เข้า <https://github.com> แล้วลงชื่อเข้าใช้ (ถ้ายังไม่มีบัญชี ให้สมัครก่อน — ฟรี)
2. กด **+** มุมขวาบน → **New repository**
3. ตั้งชื่อ เช่น `hongnites` → เลือก **Public** → กด **Create repository**
4. ในหน้า repository กด **uploading an existing file**
5. ลากไฟล์ **`index.html`** (และ `README.md` ถ้าต้องการ) มาวาง → กด **Commit changes**
6. ไปที่แท็บ **Settings** → เมนูซ้าย **Pages**
7. ที่ **Source** เลือก `Deploy from a branch` → Branch: **main** / โฟลเดอร์ **/ (root)** → กด **Save**
8. รอประมาณ 1–2 นาที เว็บจะพร้อมใช้งานที่

```
https://<ชื่อผู้ใช้ GitHub ของท่าน>.github.io/hongnites/
```

## 💾 ข้อควรทราบเรื่องการเก็บข้อมูล

ระบบนี้เป็นเว็บไฟล์เดียว ทำงานได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล
ข้อมูล (สมาชิก ไฟล์ ข้อความ ปฏิทิน สถิติ) จะถูกเก็บไว้ใน **เบราว์เซอร์ของแต่ละเครื่อง**
(localStorage และ IndexedDB)

**หมายความว่า:**

- ✅ เปิดใช้งานได้ทันที ไม่มีค่าใช้จ่าย ไม่ต้องตั้งค่าอะไรเพิ่ม
- ✅ ข้อมูลยังอยู่แม้ปิดเบราว์เซอร์หรือปิดเครื่อง
- ⚠️ ไฟล์ที่อัปโหลดจากเครื่องหนึ่ง **จะไม่ปรากฏบนเครื่องอื่น**
- ⚠️ หากล้างประวัติการใช้งานเบราว์เซอร์ ข้อมูลจะหายไป

**คำแนะนำ:** ผู้ดูแลระบบควรกด **⚙️ ตั้งค่าระบบ → 📦 สำรองทั้งหมด (รวมไฟล์แนบ)** เป็นประจำ
และสามารถกู้คืนได้ด้วยปุ่ม **📤 กู้คืนจากไฟล์สำรอง**

หากต้องการให้ครูทุกคนเห็นข้อมูลชุดเดียวกันแบบออนไลน์จริง สามารถต่อยอดเชื่อมฐานข้อมูล
Firebase หรือ Google Sheets เพิ่มเติมได้ในภายหลัง
